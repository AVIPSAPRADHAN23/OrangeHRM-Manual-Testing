# OrangeHRM Manual Testing Project

## Project Overview
This project focuses on manual testing of the OrangeHRM Open Source Demo Application to validate login functionality, password validation, dashboard navigation, and basic user interface behavior.

## Application Under Test
- **Application:** OrangeHRM Demo
- **Website:** https://opensource-demo.orangehrmlive.com/
- **Testing Type:** Manual Testing
- **Browser:** Google Chrome
- **Platform:** Windows

## Testing Scope
- Login with valid credentials
- Login with invalid username and password
- Empty-field validation
- Password masking and visibility
- Forgot Password navigation
- Username with leading and trailing spaces
- Repeated invalid login attempts
- Dashboard navigation
- Logout functionality
- Sidebar navigation
- Browser Back behavior
- Basic UI and keyboard validation

## Tools Used
- Microsoft Excel – Test case documentation
- Google Chrome – Application testing
- Windows Snipping Tool – Screenshots
- GitHub – Project documentation and version control

## Project Structure
- **Test-Plan:** Test planning document
- **Test-Cases:** Test scenarios and test cases
- **Screenshots:** Testing evidence
- **Bug-Reports:** Defect documentation
- **Test-Execution-Report:** Execution summary and conclusion
