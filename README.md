# OrangeHRM Manual Testing Project

## Project Overview
This project focuses on manual testing of the OrangeHRM Open Source Demo application. The objective is to verify login functionality, input validation, dashboard navigation, and basic user interactions.

**Application:** [OrangeHRM Demo](https://opensource-demo.orangehrmlive.com/)

## Testing Scope
- Login and logout functionality
- Positive and negative login scenarios
- Username and password validation
- Password visibility
- Forgot Password navigation
- Dashboard verification
- Sidebar navigation
- Browser Back button after logout
- Basic UI and usability checks

## Testing Types
- Manual Testing
- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing

## Tools Used
- Microsoft Excel – Test cases, test plan and bug report
- Microsoft Word – Test execution report
- Google Chrome – Test execution
- GitHub – Project documentation and version control

## Project Deliverables
1. Test Plan
2. Test Scenarios and Test Cases
3. Test Execution Summary
4. Bug Report
5. Test Execution Report
6. Application Screenshots

## Defect Summary
One potential issue was documented:

**BR-001:** Dashboard content appeared after clicking the browser Back button following logout. Refreshing redirected to the login page. This issue is marked Open – Needs Investigation.

## Project Outcome
Performed manual testing of key OrangeHRM application workflows, documented test results, and recorded a potential defect with reproduction steps.
